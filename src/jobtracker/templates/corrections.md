# Corrections

A log of lessons learned when a score turned out to be wrong, in either direction: too generous,
too harsh, or based on a misreading of a posting or of your own preferences.

This file is part of the scoring stack (see `SCORING.md`): a scoring agent should read it
alongside `RUBRIC.md` and `PREFERENCES.md`, and a correction added here should be treated as a
standing instruction, not a one-off note.
When you disagree with a score and figure out why, add an entry here so the same mistake doesn't
repeat on the next posting.
If a correction is significant enough that it would change how postings get scored going forward,
also bump `current_version` in `SCORING.md` per its changelog rules.

## Format

Each entry: what happened, what the correct read should have been, and the general rule to apply
going forward (not just a fix for that one posting).

```
### YYYY-MM-DD: <short description>

**What happened:** <the posting, the score it got, why that was wrong>

**Correct read:** <what the score/reasoning should have been>

**Going forward:** <the general rule to apply to future postings like this>
```
